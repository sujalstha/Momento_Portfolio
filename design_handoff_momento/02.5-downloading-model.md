# Screen 2.5 — Downloading AI Coaching Model

> **Where it sits in the flow:** after the 5-step onboarding completes, before the user lands on the Home (Run) tab. Shown once per device/install. If the model is already present on launch, **skip this screen entirely** and route straight to Home.
>
> **Why it exists:** the on-device coaching model is ~340 MB. Downloading it after auth (instead of bundling it in the app binary) keeps the App Store install small and lets us ship model updates without an app review cycle.

   - **10pt gap**

3. **Progress card** (pinned just above the bottom safe area, see below)
4. **Tip footer** — `Tip: Echo works offline once installed.` — 13pt regular, `text-3` color, centered, 6pt gap above the safe area

## Progress card (the centerpiece)

A glass card (`Material.ultraThinMaterial`, 18pt corner radius, the standard hairline + drop shadow recipe from the design system).

**Card padding:** 18pt all around.

**Inside the card** — three rows, vertically stacked:

### Row 1 — Label + percent (`HStack`, baseline aligned, 12pt bottom margin)

- **Left:** `Coaching model · v1.0` — 13pt semibold, primary text color
- **Right:** `64%` — the number is **22pt bold**, tabular numerals, `-2%` tracking; the `%` symbol is **14pt** in `text-3` color with 2pt leading whitespace

### Row 2 — The progress bar

**Track:**
- Height: **8pt**
- Corner radius: **999pt** (full pill)
- Fill: `Color.black.opacity(0.08)`
- Inset shadow on the track to make it feel recessed:
  - Inset top hairline: `Color.black.opacity(0.06)`
  - Inset bottom hairline: `Color.white.opacity(0.40)`

**Fill:**
- Same height + corner radius as the track
- Horizontal linear gradient from `#E48700` (left) → `#FFA94D` (right)
- Soft outer glow: `Color(hex: "E48700").opacity(0.45)`, blur radius 16pt
- Inset top highlight: 0.5pt of `Color.white.opacity(0.35)` along the top edge
- **Leading-edge shine:** a 28pt-wide horizontal gradient from `clear → Color.white.opacity(0.55)` clipped to the right edge of the fill — gives the "in motion" feel without being gimmicky

### Row 3 — Metadata (`HStack`, 10pt top margin)

- **Left:** `218 MB of 340 MB` — 13pt regular, `text-3`, tabular numerals
- **Right:** `~14 sec left` — 13pt regular, `text-3`, tabular numerals

Both update live as the download progresses.

```swift
                        .frame(width: 28)

                    )
                    .animation(.easeInOut(duration: 0.4), value: progress)
            }
        }
        .frame(height: 8)
    }
}
```

### `ModelDownloader` skeleton

```swift
@MainActor
final class ModelDownloader: ObservableObject {

    struct State: Equatable {
        var bytesReceived: Int64 = 0
        var bytesTotal:    Int64 = 340 * 1024 * 1024     // 340 MB target
        var startedAt:     Date  = .now
        var isComplete:    Bool  = false

        var fraction: Double { bytesTotal == 0 ? 0 : Double(bytesReceived) / Double(bytesTotal) }
        var percent:  Int    { Int((fraction * 100).rounded()) }

        var bytesText: String {
            "\(formatMB(bytesReceived)) of \(formatMB(bytesTotal))"
        }

        var etaText: String {
            let elapsed = Date.now.timeIntervalSince(startedAt)
            guard bytesReceived > 0, elapsed > 0.5 else { return "calculating…" }
            let bps = Double(bytesReceived) / elapsed
            let remaining = Double(bytesTotal - bytesReceived) / max(bps, 1)
            return "~\(formatTime(remaining)) left"
        }

        var voiceOverLabel: String {
            "Downloading coaching model. \(percent) percent complete. \(etaText)."
        }

        private func formatMB(_ b: Int64) -> String {
            let mb = Double(b) / 1_048_576
            return String(format: "%.0f MB", mb)
        }
        private func formatTime(_ sec: Double) -> String {
            if sec < 60 { return "\(Int(sec.rounded())) sec" }
            return "\(Int((sec / 60).rounded())) min"
        }
    }

    @Published private(set) var state = State()

    func start() async {
        guard let url = URL(string: "https://api.momento.app/models/coach-v1.bin") else { return }

        // Use a delegate to get progress updates
        let task = URLSession.shared.downloadTask(with: url)
        // ... wire delegate, update state.bytesReceived on each callback ...
        // On completion: persist file to Application Support, set state.isComplete = true,
        // and post a notification AppRouter listens to.
    }
}
```

## Behavior & edge cases

| Situation | Behavior |
|---|---|
| Model already present on launch | Skip this screen — straight to Home |
| Active Wi-Fi / unmetered | Auto-start the download on appear |
| Cellular only | Show a one-time confirm: "Download 340 MB on cellular? You can also wait until you're on Wi-Fi." with `Download now` and `Wait for Wi-Fi` buttons |
| Network drops mid-download | Pause the bar (stop the shine animation), swap the tip line for "Connection lost. Retrying…" in `verm` color, and `URLSession` resumes when reachable |
| User backgrounds the app | Continue with a background `URLSession` configuration; restore state on foreground |
| Download fails permanently | Replace progress card with an inline error glass card + `Try again` button |
| Disk full | Detect at start, surface a glass alert: "Not enough space. Free at least 400 MB to install Echo." |

## Accessibility — non-negotiable

- The whole view is one accessibility element with a combined label that VoiceOver re-reads on every 5% increment (don't spam it on every byte).
- On screen appear, **speak via `AVSpeechSynthesizer`**: *"Downloading Echo. This only happens once. I'll let you know when I'm ready."* — Echo introducing itself sets the tone for the rest of the app.
- Honor `accessibilityReduceMotion`: drop the leading-edge shine animation; the progress bar still fills, but without the moving highlight.
- Honor `accessibilityReduceTransparency`: replace the `Material.ultraThinMaterial` on the progress card with `Color(.secondarySystemBackground)`.
- The orb's animation should also stop pulsing under Reduce Motion.
- Don't show any "tap to skip" affordance — the model is required.

## Telemetry to capture

- `model_download_started` — with reachability (`wifi` / `cellular`) and free disk MB
- `model_download_progress` — fired at 25 / 50 / 75% checkpoints
- `model_download_completed` — with total duration and average MB/s
- `model_download_failed` — with error code; show user-facing message + retry

## Acceptance criteria

- [ ] Screen appears once after onboarding step 5 completes
- [ ] Skipped on subsequent launches if the model is already installed
- [ ] Progress bar updates at least every 100 ms and feels smooth (no jank at 25%, 50%, 75% boundaries)
- [ ] Percent number, byte count, and ETA all use tabular numerals — no digit-width jitter
- [ ] Glass material renders correctly over the dawn backdrop
- [ ] Reduce Motion users do not see the shine sweep or orb pulse
- [ ] VoiceOver speaks the combined status when entering the screen and on each 5% increment
- [ ] Successful completion transitions to Home with a fade (350 ms ease-out)
- [ ] Failed downloads show inline error + retry, never crash, never silently dump the user back to onboarding

## Notes for Claude Code

- Use the design tokens (`DT.*`) already defined in the main handoff README. **Don't redefine colors or radii in this file.**
- The `EchoOrb` view should be a reusable component — it's also used on Sign-in (196pt) and during onboarding (200pt with pulse ring). Make it parametric on size + pulse on/off.
- The progress fraction must be a `Double` driving `.animation(.easeInOut(duration: 0.4), value: progress)` — animating raw `Int` percent values produces a stepped, ugly bar.
- Don't try to draw the orb's gradient with `LinearGradient` — it needs two stacked `RadialGradient`s (white highlight + blue body) plus inner shadow simulation via overlays.
